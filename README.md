#  Manager Library & Application

##  Описание

Проект состоит из двух частей:
1. **Библиотека Manager** - для работы с журналом сообщений с уровнями важности
2. **Консольное приложение** - интерфейс для управления журналом

---

##  Библиотека Manager

### Назначение
Библиотека предоставляет класс `Manager` для ведения журнала сообщений с тремя уровнями важности.

### Уровни важности
```cpp
enum class Level {
    IMPORTANT = 1,    // Важное сообщение
    MEDIUM = 2,       // Средней важности
    UNIMPORTANT = 3   // Неважное сообщение
};
```

### Основные методы

| Метод | Описание |
|-------|----------|
| `Manager()` | Конструктор по умолчанию |
| `Manager(std::string, Level)` | Конструктор с именем журнала и уровнем по умолчанию |
| `bool Write(std::string&, Level)` | Запись сообщения в журнал |
| `std::vector<Message> Read()` | Чтение всех сообщений из журнала |
| `void ChangeDefaultLevel(Level)` | Изменение уровня важности по умолчанию |
| `std::string ConvertRow(std::string&, Level)` | Форматирование сообщения для записи |
| `bool WriteToJournal(std::string&)` | Запись форматированной строки в журнал |
| `Level GetDefaultLevel()` | Получение текущего уровня по умолчанию |

### Структура сообщения
```cpp
struct Message {
    std::string lvl;      // Уровень важности (1-3)
    std::string data;     // Дата и время
    std::string message;  // Текст сообщения
};
```

## Консольное приложение

### Запуск
```bash
./main -jn <имя_журнала> -dl <уровень_важности>
```

#### Параметры запуска
| Параметр | Описание |
|----------|----------|
| `-jn, --journalname <name>` | Имя файла журнала |
| `-dl, --defaultlevel <1-3>` | Уровень важности по умолчанию |
| `-h, --help` | Показать справку |

#### Примеры
```bash
# Запуск с журналом "my_log" и уровнем по умолчанию "IMPORTANT"
./main -jn my_log -dl 1

# Запуск с журналом "system" и уровнем по умолчанию "MEDIUM"
./main --journalname system --defaultlevel 2
```

### Меню приложения

| Команда | Описание |
|---------|----------|
| `1` | Внести сообщение в журнал |
| `2` | Прочитать все сообщения из журнала |
| `3` | Показать текущий уровень важности по умолчанию |
| `4` | Изменить уровень важности по умолчанию |
| `5` | Очистить журнал |
| `6` | Вывести сообщения с заданным уровнем важности |
| `0` | Выйти из приложения |

### Особенности работы

1. **Многопоточность**: Запись сообщений выполняется в отдельном потоке
2. **Синхронизация**: Используется мьютекс для предотвращения конфликтов при чтении/записи
3. **Фильтрация**: Сообщения с уровнем важности ниже установленного по умолчанию не записываются

##  Формат журнала

Каждая запись в журнале имеет формат:
```
 <уровень>|<дата_время>|<сообщение>
```
